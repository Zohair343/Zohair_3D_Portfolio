# Ask Zohair: how the RAG pipeline works

1. **Curated sources.** `content/portfolio.json` (the same file the site renders) plus approved Markdown in `content/knowledge/`. Contact details, the phone number and visitor messages are never ingested; `ingest.py` also strips anything that looks like a phone number or email.
2. **Chunking.** One chunk per panel / heading (39 today). Project chunks start with `Project: <name> (<genre>, <engine>)`, so a mechanic stays attached to its game. Each chunk stores `id`, `title`, `section`, `url` (e.g. `/projects/scorched#combo`) and `project`.
3. **Embeddings + index.** Gemini `gemini-embedding-001` (768-d; `RETRIEVAL_DOCUMENT` for passages, `RETRIEVAL_QUERY` for questions), normalised and stored in FAISS `IndexFlatIP`. `python ingest.py` writes it to `backend/index/`; if that file is missing or doesn't match the current content and embedding model, the server rebuilds it on first use and caches it, so a deployment can't serve a stale index. A keyless local model (`EMBED_PROVIDER=local`, bge-small) is used by the offline tests.
4. **Retrieval.** The question is embedded with the same model's query encoder. Scores = cosine similarity + 0.25 × IDF-weighted keyword overlap (added after "NavMesh" questions missed the NavMesh panels with dense-only retrieval). Top 6, plus the best 2–3 chunks for **each project named** in the question so comparisons have evidence for both sides. Short follow-ups are expanded with the previous question.
5. **Generation.** The chunks go to Gemini (`gemini-3.8-flash`, JSON output constrained by a schema; Claude is a switchable alternative) with a system prompt that restricts it to the sources, asks for third-person, short answers, and requires an explicit "the portfolio doesn't include…" when unsupported. Output is constrained to JSON: `{status: answered|insufficient, answer, citations[]}`.
6. **Server-side guards.** Citations not among the retrieved ids are dropped; an "answered" reply with no valid citation is downgraded to *insufficient*; safety blocks, truncation, bad JSON and provider/network/auth failures return an error code (HTTP 502/503), never an answer. Keys stay on the server; requests are rate-limited per IP.
7. **UI.** Speaker labels, `role="log"` live region, Enter/Shift+Enter, loading state, clickable citations that open and focus the cited panel, and provider errors shown as a red system notice (not a speech bubble) with a retry button.

Evaluation: `docs/evaluation.md` (generated by `backend/evaluate.py`).
